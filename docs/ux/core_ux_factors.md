# Exercise 11.1
## Overview of Consolidated UX Factors

| UX Factor                         | Definition                                                                                                                          | Example                                                                                          |
|-----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| **Appearance/Attractiveness**     | The product is attractive, beautiful, and visually appealing.                                                                        | A visually appealing app interface with a consistent color scheme and clear icons.               |
| **Completeness**                  | The user feels that the provided information and features are complete.                                                              | An e-commerce site offers comprehensive product details, customer reviews, and related items.   |
| **Controllability/Dependability** | The product responds to user interactions in a predictable and reliable way.                                                         | Buttons react immediately and consistently, without delays or unexpected states.                |
| **Convenience**                   | The product makes the user’s life easier and/or simplifies task completion.                                                          | With one click, all previously entered form fields are auto-filled.                              |
| **Craftsmanship**                 | The product feels high-quality and well-made.                                                                                        | High-resolution graphics and smooth animations convey a sense of premium quality.                |
| **Ease of use**                   | The product is easy to use.                                                                                                          | Clear navigation, self-explanatory buttons, and understandable error messages.                   |
| **Efficiency**                    | The user achieves their goals with minimal time and effort.                                                                          | A fast search function with autocomplete reduces clicks and typing.                              |
| **Emotion/Affect**                | The product elicits positive or negative emotions.                                                                                   | A cheerful micro-animation upon task completion generates delight.                              |
| **Flexibility**                   | The user can adapt the product to their needs and workflows.                                                                         | Dark mode, customizable toolbars, and reusable templates.                                       |
| **Fun**                           | Interacting with the product is enjoyable.                                                                                           | Gamification elements like badges or progress levels motivate further use.                      |
| **Helpfulness**                   | The product supports the user.                                                                                                       | A context-sensitive help feature explains functionality right where it’s needed.                |
| **Identity**                      | The user can identify with the product and adopt its characteristics.                                                                 | Personalized avatars or themes reflect the user’s personality.                                  |
| **Immersion**                     | The user loses track of time while using the product.                                                                                | Full-screen mode and a distraction-free interface enable deep focus.                            |
| **Intuitive Operation**           | The user can operate the product without training or instruction.                                                                     | Drag-and-drop functionality for moving elements is self-explanatory.                             |
| **Learnability/Perspicuity**      | The product is easy to learn; its operation is clear and transparent.                                                                 | An onboarding tour with brief tips eases the learning curve.                                    |
| **Loyalty**                       | The user is convinced by the product, recommends it, and uses it repeatedly.                                                          | Loyalty programs and referral bonuses encourage repeat usage.                                   |
| **Novelty**                       | The product is new or innovative.                                                                                                    | A novel interface concept enabling previously unseen interactions (e.g., voice UI).             |
| **Originality**                   | The product is interesting and unusually designed.                                                                                    | A creative, unexpected layout that surprises and invites exploration.                           |
| **Overall**                       | Describes the general overall impression: the product as a whole feels good or bad.                                                   | Star ratings in the app store summarizing users’ overall evaluation.                            |
| **Relevancy**                     | The provided information is relevant and important to the user.                                                                       | A news app shows only topics relevant to the user’s interests.                                   |
| **Pragmatic Quality**             | The product is practical and functional.                                                                                              | Clear prioritization of core features without superfluous options.                              |
| **Simplicity**                    | The product is simple in operation.                                                                                                   | A minimalist interface with only essential elements.                                            |
| **Social Influences**             | Use supports social interaction or self-presentation.                                                                                 | Share buttons for social networks and integrated community features.                            |
| **Stimulation**                   | Working with the product encourages the user to use it again.                                                                         | Push notifications remind the user of upcoming tasks or updates.                                |
| **Trust/Credibility**             | The product appears trustworthy.                                                                                                      | SSL certification and clear privacy notices create a sense of security.                         |

> **Source of definitions:**  
> Hinderks et al., “Applicability of User Experience and Usability Questionnaires”, *Journal of Universal Computer Science*, vol. 25, no. 13 (2019)
